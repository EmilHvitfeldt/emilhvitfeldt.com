# emilhvitfeldt.com

## Keep Watercolor Wash `full/` in sync with the keynote repo

`project/watercolor-wash/full/` is a copy of the editor in `~/Desktop/keynote` (`index.html`, `css/style.css` and the `js/` files that `index.html` loads, not `embed.js`). That repo is the source of truth. When it changes, copy the changes here so the two stay identical, and don't edit `full/` directly without making the same change there.

`project/watercolor-wash/app.html` is the separate simplified single-file version and is not part of this sync.
