Dino Palette Swap recolors a fixed set of eight dinosaur illustrations from a few shared colors. Body, spots, belly and accent each get a color picker, while the shade and the lighter accent are derived from them, so the whole set stays consistent as you swap palettes. Eyes, mouths and claws keep their original colors.

Everything runs client-side in a single HTML file, [launch it here](app.html). Recolored dinosaurs download as SVG, or all together as a PNG sheet.
