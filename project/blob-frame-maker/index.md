Blob Frame Maker builds the kind of photo mask where a grid of rounded cells fuses into one smooth connected shape. Fill cells to draw the frame, cut the seam between two of them to open a channel, and click a corner to change its radius or run a diagonal neck across it. Eight presets recreate a reference set of these designs.

Everything runs client-side in a single HTML file, [launch it here](app.html). Frames export as SVG or PNG.
